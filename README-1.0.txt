GymEssentials 1.0
=================

This is the rebuilt 1.0 foundation release based directly on the uploaded 3.6 beta files.

Important:
- Keep your existing 3.6 icons/ folder when copying this build if the icons were not included in the uploaded files.
- 1.0 keeps the same localStorage key, so an existing 3.6 installation on the same origin can be migrated by opening this version.
- Export a backup before testing anyway.
- The old 3.6 files are not modified by this build.

1.0 foundation changes:
- Versioned app/data schema
- Stable exercise library IDs and future metadata fields
- Stable program/session identity foundation
- Structured exerciseRecords in sessions
- Migration-ready backup format
- Safer, normalized import with restore summary
- Service-worker cache bumped to 1.0
