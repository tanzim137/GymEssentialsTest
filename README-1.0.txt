GymEssentials 1.0
=================

This is the rebuilt 1.0 platform release based directly on the GymEssentials 3.6 beta codebase.

Important:
- 1.0 uses a new localStorage namespace and starts clean.
- The 3.6 beta data is intentionally NOT imported automatically.
- The original ChatGPT workout program is preserved inside 1.0 as the "Original Program".
- The existing 3.6 workout engine remains underneath the new 1.0 application shell.
- Copy your existing 3.6 `icons` folder into this folder before deploying if you want the existing GymEssentials icon/PWA artwork.
